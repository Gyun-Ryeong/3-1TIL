# PRD: 상식 퀴즈 게임

## 1. 개요

### 제품 설명
사용자가 다양한 카테고리의 상식 문제를 풀며 지식을 테스트하고, 점수와 순위를 기록할 수 있는 4지선다 퀴즈 게임

### 타겟 사용자
상식 퀴즈를 즐기는 일반 사용자 (연령 무관, 학습 목적 없이 재미로 즐기는 캐주얼 플레이어)

### 목표
- 흥미롭고 교육적인 퀴즈 경험 제공
- 카테고리별 지식 수준 파악 가능
- 점수 기록을 통한 반복 플레이 동기 부여

### v1.0 포함 항목
- 4지선다 객관식 퀴즈 (한국사, 과학, 지리, 일반상식 / 각 10문제)
- 정답/오답 즉시 피드백
- 최종 점수 및 등급 표시
- 로컬 랭킹 기록 (localStorage)

### v1.0 제외 항목
- 회원가입 / 로그인
- 서버 기반 글로벌 랭킹
- 난이도 선택
- 타이머 모드
- 오답 해설
- 어드민(문제 관리) 기능
- 멀티플레이어
- 다국어 지원

## 2. 기능 요구사항

### 2.1 퀴즈 구성

| 항목 | 내용 |
|------|------|
| 문제 형식 | 4지선다 객관식 |
| 카테고리 | 한국사, 과학, 지리, 일반상식 |
| 카테고리별 문제 수 | 10문제 |
| 총 문제 수 | 40문제 |

#### 카테고리 상세
- **한국사**: 삼국시대~현대사, 인물, 사건, 문화재 등
- **과학**: 물리, 화학, 생물, 지구과학 기초 상식
- **지리**: 한국 지리, 세계 지리, 수도, 지형 등
- **일반상식**: 시사, 문화, 스포츠, 언어, 예술 등

### 2.2 게임 플로우

```
메인 화면
    ↓
카테고리 선택 (또는 전체 랜덤)
    ↓
문제 출제 (1문제씩 순차 표시)
    ↓
보기 4개 중 1개 선택
    ↓
즉시 정답/오답 피드백
    ↓
다음 문제 → (반복)
    ↓
카테고리 종료 → 카테고리별 결과 표시
    ↓
최종 점수 및 순위 기록
```

### 2.3 문제 출제

- 각 카테고리 10문제를 순서대로 출제
- 문제당 보기 4개 표시 (정답 1개, 오답 3개)
- 현재 진행 상황 표시 (예: 3/10)
- 문제당 제한 시간 없음 (기본), 선택적으로 타이머 모드 지원

### 2.4 즉시 피드백

정답 선택 시:
- 정답 보기를 초록색으로 강조
- "정답입니다!" 메시지 표시
- 해당 문제에 대한 간단한 해설 표시 (선택)

오답 선택 시:
- 선택한 오답 보기를 빨간색으로 강조
- 정답 보기를 초록색으로 표시
- "오답입니다. 정답은 OO입니다." 메시지 표시
- 해당 문제에 대한 간단한 해설 표시 (선택)

### 2.5 점수 계산

| 항목 | 점수 |
|------|------|
| 정답 | +10점 |
| 오답 | 0점 |
| 카테고리 만점 | 100점 |
| 전체 만점 | 400점 |

### 2.6 최종 결과 화면

- 총점 표시 (예: 280/400)
- 정답률 표시 (예: 70%)
- 카테고리별 점수 세부 내역
- 등급 표시

| 정답률 | 등급 |
|--------|------|
| 90% 이상 | S |
| 80% ~ 89% | A |
| 70% ~ 79% | B |
| 60% ~ 69% | C |
| 59% 이하 | D |

### 2.7 순위 기록

- 플레이어 닉네임 입력 후 점수 저장
- 상위 10위 랭킹보드 표시
- 로컬 스토리지 기반 저장 (서버 불필요)
- 항목: 순위, 닉네임, 점수, 정답률, 플레이 일시

## 3. 화면 구성

### 3.1 메인 화면
- 게임 타이틀
- [게임 시작] 버튼
- [랭킹 보기] 버튼
- [카테고리 선택] 옵션

### 3.2 카테고리 선택 화면
- 4개 카테고리 카드 표시
- [전체 랜덤] 선택 옵션 (40문제 랜덤 출제)

### 3.3 퀴즈 진행 화면
- 상단: 카테고리명 / 진행률 (N/10) / 현재 점수
- 중앙: 문제 텍스트
- 하단: 보기 ①②③④ 버튼

### 3.4 피드백 화면
- 정답/오답 결과 표시
- 정답 강조 표시
- 해설 텍스트 (선택)
- [다음 문제] 버튼

### 3.5 결과 화면
- 총점 / 정답률 / 등급
- 카테고리별 점수 바 차트
- 닉네임 입력 폼
- [랭킹 저장] 버튼
- [다시 하기] / [메인으로] 버튼

### 3.6 랭킹 화면
- TOP 10 순위표
- [메인으로] 버튼

## 4. 비기능 요구사항

- **플랫폼**: 웹 브라우저 (모바일/데스크톱 반응형)
- **기술 스택**: HTML, CSS, JavaScript (프레임워크 선택 자유)
- **데이터 저장**: localStorage (서버 없이 동작)
- **성능**: 페이지 로딩 2초 이내, 피드백 응답 즉시
- **접근성**: 키보드 조작 지원 (①②③④ 키 또는 방향키)
