data.js 파일에 새 퀴즈 문제를 추가해 줘.

$ARGUMENTS에서 첫 번째 값을 카테고리, 두 번째 값을 난이도로 사용해.

## 처리 순서

1. data.js를 읽어서 현재 가장 큰 id 값을 확인하고, 새 문제의 id는 그 다음 번호로 지정해.
2. 사용자에게 아래 항목을 요청해:
   - question: 문제 내용
   - options: 보기 4개 (배열)
   - answer: 정답 인덱스 (0~3)
3. 아래 검증 가이드라인을 모두 통과한 경우에만 data.js에 추가해.

## 검증 가이드라인

- [ ] question이 비어있지 않고, 물음표(?)로 끝나야 한다.
- [ ] options는 정확히 4개여야 한다.
- [ ] options 항목 중 빈 문자열이 없어야 한다.
- [ ] options 항목이 모두 서로 달라야 한다 (중복 보기 금지).
- [ ] answer는 0~3 사이의 정수여야 한다.
- [ ] 동일한 question 텍스트가 data.js에 이미 존재하면 안 된다 (중복 문제 금지).
- [ ] 카테고리는 $ARGUMENTS의 첫 번째 값을 그대로 사용한다.
- [ ] 난이도(difficulty)는 "하", "중", "상" 중 하나여야 한다. $ARGUMENTS의 두 번째 값이 이 셋 중 하나가 아니면 오류를 안내하고 중단한다.

## 검증 실패 시

검증에 실패한 항목을 구체적으로 안내하고, data.js는 수정하지 않는다.

## 추가 형식

검증을 모두 통과하면 data.js의 quizData 배열 마지막 항목 뒤에 아래 형식으로 추가해:

```js
  {
    id: <다음 id>,
    category: "<카테고리>",
    difficulty: "<난이도>",
    question: "<문제>",
    options: ["<보기1>", "<보기2>", "<보기3>", "<보기4>"],
    answer: <정답 인덱스>
  },
```

추가 완료 후 추가된 문제의 id, category, difficulty, question, 정답 보기 텍스트를 출력해.
