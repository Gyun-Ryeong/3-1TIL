data.js 파일을 읽고, 퀴즈 문제(question 필드)에서 최상급 표현이 포함된 문제를 찾아 목록으로 출력해 줘.

$ARGUMENTS 값이 있으면 해당 카테고리의 문제만 검색하고, 값이 없으면 전체 문제를 대상으로 검색해 줘.

검색할 최상급 표현 키워드:
- 가장
- 최초
- 최대
- 최고
- 최소
- 최장
- 최단
- 제일
- 유일

출력 형식:
- id, category, question, 감지된 키워드를 표 형태로 나열
- 해당 문제가 없으면 "최상급 표현 문제 없음" 출력
- 마지막에 총 개수 요약

검색 대상 파일: data.js
