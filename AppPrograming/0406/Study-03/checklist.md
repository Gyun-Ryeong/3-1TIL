# 상식 퀴즈 게임 — 구현 확인 체크리스트

---

## STEP 1 체크리스트 — 프로젝트 골격 + 문제 데이터

### 파일 구조
- [ ] `index.html` 파일이 생성되었다
- [ ] `style.css` 파일이 생성되었다
- [ ] `data.js` 파일이 생성되었다
- [ ] `app.js` 파일이 생성되었다
- [ ] `index.html`에서 `style.css`, `data.js`, `app.js`를 모두 올바르게 불러온다

### index.html 화면 구조
- [ ] `#screen-main` (메인 화면) div가 존재한다
- [ ] `#screen-category` (카테고리 선택) div가 존재한다
- [ ] `#screen-quiz` (퀴즈 진행) div가 존재한다
- [ ] `#screen-feedback` (피드백) div가 존재한다
- [ ] `#screen-result` (결과) div가 존재한다
- [ ] `#screen-ranking` (랭킹) div가 존재한다
- [ ] 초기 로드 시 메인 화면(`#screen-main`)만 보이고 나머지는 숨겨져 있다

### data.js 문제 데이터
- [ ] 한국사 문제가 정확히 10개 작성되었다
- [ ] 과학 문제가 정확히 10개 작성되었다
- [ ] 지리 문제가 정확히 10개 작성되었다
- [ ] 일반상식 문제가 정확히 10개 작성되었다
- [ ] 모든 문제 객체에 `id`, `category`, `question`, `options`, `answer` 필드가 있다
- [ ] 모든 문제의 `options` 배열 길이가 4개다
- [ ] 모든 문제의 `answer` 값이 0~3 범위 안에 있다
- [ ] 브라우저에서 `index.html`을 열었을 때 콘솔 에러가 없다

---

## STEP 2 체크리스트 — 게임 로직 구현

### 화면 전환
- [ ] 메인 화면 → 카테고리 선택 화면 전환이 동작한다
- [ ] 카테고리 선택 → 퀴즈 진행 화면 전환이 동작한다
- [ ] 퀴즈 진행 → 피드백 화면 전환이 동작한다
- [ ] 피드백 → 다음 문제(퀴즈 진행) 전환이 동작한다
- [ ] 마지막 문제 피드백 → 결과 화면으로 전환된다

### 카테고리 및 문제 출제
- [ ] 카테고리 4개가 선택지로 표시된다
- [ ] "전체 도전" 선택 시 40문제가 랜덤 셔플되어 출제된다
- [ ] 특정 카테고리 선택 시 해당 카테고리 문제만 10개 출제된다
- [ ] 진행률이 "N / 10" 또는 "N / 40" 형식으로 표시된다
- [ ] 현재 획득 점수가 퀴즈 화면에 실시간으로 표시된다

### 정답/오답 피드백
- [ ] 정답 선택 시 해당 보기 버튼이 초록색으로 강조된다
- [ ] 정답 선택 시 "정답입니다!" 메시지가 표시된다
- [ ] 오답 선택 시 선택한 보기 버튼이 빨간색으로 강조된다
- [ ] 오답 선택 시 정답 보기 버튼이 초록색으로 강조된다
- [ ] 오답 선택 시 "오답입니다. 정답은 OO입니다." 메시지가 표시된다

### 점수 및 결과 화면
- [ ] 정답 시 점수가 +10점 증가한다
- [ ] 오답 시 점수 변화가 없다
- [ ] 결과 화면에 총점(예: 280 / 400)이 표시된다
- [ ] 정답률(%)이 올바르게 계산되어 표시된다
- [ ] 정답률에 따른 등급(S/A/B/C/D)이 올바르게 표시된다

## STEP 3 체크리스트 — 랭킹 기능 + UI 완성 + 최종 점검

### 랭킹 기능
- [ ] 결과 화면에 닉네임 입력 폼이 표시된다
- [ ] [랭킹 저장] 클릭 시 `localStorage`의 `"quizRankings"` 키에 데이터가 저장된다
- [ ] 저장 데이터에 `nickname`, `score`, `accuracy`, `date` 필드가 모두 있다
- [ ] 날짜가 "YYYY-MM-DD HH:mm" 형식으로 저장된다
- [ ] 랭킹이 점수 내림차순으로 정렬된다
- [ ] 상위 10개 기록만 유지되고 11위 이하는 자동 삭제된다
- [ ] 랭킹 화면에 순위 / 닉네임 / 점수 / 정답률 / 날짜 컬럼이 표시된다
- [ ] 페이지 새로고침 후에도 랭킹 데이터가 유지된다

### UI 스타일
- [ ] 전체 배경이 캐주얼하고 밝은 분위기로 스타일링되었다
- [ ] 카테고리 선택 화면이 카드형 레이아웃으로 표시된다
- [ ] 카테고리 카드에 hover 효과가 적용되어 있다
- [ ] 보기 버튼의 기본/정답/오답 상태 색상이 구분되어 있다
- [ ] 등급(S/A/B/C/D)이 크고 굵게, 등급별 색상으로 표시된다

### 접근성 및 반응형
- [ ] 숫자키 1~4로 보기를 선택할 수 있다
- [ ] 피드백 화면 표시 후 [다음 문제] 버튼에 포커스가 자동 이동된다
- [ ] 모바일(480px) 화면에서 레이아웃이 깨지지 않는다

### 최종 통합 점검
- [ ] 카테고리별 10문제, 전체 40문제가 빠짐없이 모두 출제된다
- [ ] 전체 도전 시 매 플레이마다 문제 순서가 다르게 섞인다
- [ ] 게임 전체 플로우(메인→카테고리→퀴즈→피드백→결과→랭킹)가 끊김 없이 동작한다
