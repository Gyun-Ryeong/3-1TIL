# PRD Step 3 — 사용자 프로필 및 레시피 저장

## 개요
로그인/회원가입 시스템과 개인 대시보드를 추가하여
사용자가 마음에 드는 레시피를 저장하고 관리할 수 있도록 합니다.

## 사용 기술
- **Step 1·2 기반** 위에 기능 추가
- **데이터 저장**: JSON 파일 기반 로컬 저장 (프로토타입)
- **인증**: Streamlit session_state 기반 (프로토타입)

## 기능 요구사항

### 1. 회원가입 / 로그인
- 사이드바 상단에 로그인 상태 표시
- 로그인 폼: 아이디 + 비밀번호
- 회원가입 폼: 아이디 / 비밀번호 / 닉네임
- 사용자 정보는 `data/users.json`에 저장
- 로그아웃 버튼

### 2. 레시피 저장
- Step 2 레시피 카드의 **[저장]** 버튼 활성화
- 로그인 상태일 때만 저장 가능 (비로그인 시 안내 메시지)
- 저장된 레시피는 `data/saved_recipes.json`에 사용자별 보관
- 중복 저장 방지 및 저장 완료 알림

### 3. 나의 레시피 탭
- 사이드바 **[나의 레시피]** 메뉴
- 저장한 레시피 목록 표시 (카드 형태)
- 레시피 삭제 버튼
- 저장 날짜 표시

### 4. 개인 대시보드
- 사이드바 **[대시보드]** 메뉴
- 통계 표시:
  - 총 저장 레시피 수
  - 총 재료 인식 횟수
  - 가장 많이 사용한 재료 Top 3
  - 선호 난이도 분포 (차트)

## 파일 구조 (추가·변경)
```
Study-04/
├── app.py                   # 전체 메뉴 통합
├── src/
│   ├── config.py
│   ├── api_client.py

├── data/
│   ├── users.json           # 사용자 계정 정보

```
