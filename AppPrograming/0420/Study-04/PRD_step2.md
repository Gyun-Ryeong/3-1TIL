# PRD Step 2 — 레시피 생성 시스템

## 개요
Step 1에서 인식한 재료를 기반으로 맞춤 레시피를 생성하고,
재료 편집 및 레시피 검색·필터링 기능을 추가합니다.

## 사용 기술
- **Step 1 기반** 위에 기능 추가
- **텍스트 생성 모델**: `qwen/qwen3.6-plus:free` (OpenRouter)
  - rate-limit 시 폴백: `openai/gpt-oss-20b:free`
- **이미지 인식 모델**: `google/gemma-3-27b-it:free` (Step 1 유지)

## 기능 요구사항

### 1. 재료 편집
- Step 1에서 인식된 재료 목록을 편집 가능하게 표시
- 재료 추가 / 삭제 버튼
- 수동 재료 입력 텍스트박스

### 2. 레시피 생성 (AI 호출)
- 사이드바에 **[레시피 생성]** 메뉴 추가
- 인식·편집된 재료 목록을 텍스트 생성 모델에 전송
- 프롬프트:
  ```
  다음 재료들로 만들 수 있는 레시피 3가지를 추천해줘.
  재료: {재료 목록}
  각 레시피는 JSON 형식으로 반환해줘:
  {
    "recipes": [{
      "name": "요리명",
      "difficulty": "난이도(쉬움/보통/어려움)",
      "time": "조리시간(분)",
      "calories": "칼로리(kcal)",
      "ingredients": ["필요재료1", "필요재료2"],
      "steps": ["1단계", "2단계", "3단계"]
    }]
  }
  ```
- 응답 JSON 파싱 후 화면 표시

### 3. 레시피 표시
- 레시피 카드 UI (요리명, 난이도 뱃지, 조리시간, 칼로리)
- 카드 클릭 시 상세보기 (재료 목록 + 조리 순서)
- 각 레시피 카드에 **[저장]** 버튼 (Step 3 연동 준비)

### 4. 필터링 및 검색
- 난이도 필터 (전체 / 쉬움 / 보통 / 어려움)
- 조리시간 필터 (30분 이하 / 1시간 이하 / 전체)
- 레시피명 검색창
